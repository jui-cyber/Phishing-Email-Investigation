# Phishing Email Investigation

## Project Overview
This project demonstrates a beginner-level
phishing email investigation workflow.

## Objectives
- Understand Indicators of Compromise (IOC).
- Identify suspicious email indicators.
- Analyze IP, domain, URL and file hashes.
- Use VirusTotal for threat intelligence.
- Use AbuseIPDB for IP reputation checks.
- Understand True Positive and False Positive.
- Classify incident severity.

## Tools Used
- VirusTotal
- AbuseIPDB
- Windows PowerShell
- Gmail
- GitHub

## Investigation Process
1. Email inspection
2. IOC identification
3. Email header analysis
4. Threat intelligence lookup
5. Alert classification
6. Severity assessment
7. Incident reporting
